# Photon Cruncher Aurora 2.1.0

- Introduces the Aurora desktop workspace for opening recordings, aligning
  events, reviewing individual trials, and exporting plots and CSV data.
- Adds named processing presets, background batch export, quality findings,
  and portable analysis provenance sidecars.
- Supports signal-only analysis when a paired 405 stream is unavailable and
  configurable polynomial control fitting.
- Preserves the corrected 405 regression used in v1.2.1. When comparing with
  earlier exports, process recordings consistently and keep older output.
